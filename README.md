# Semantic Communication Open Resources

A curated collection of research papers, open-source implementations, datasets, pretrained models, and research tools for Semantic Communication (SemCom).

This repository aims to provide an organized entry point for researchers and students to explore, study, and reproduce semantic communication research across different data modalities and application scenarios.

## 1. Text-based Semantic Communication

Research on semantic transmission, representation learning, language models, and text reconstruction.
